# Changelog

Alle Versionen von MHD Safety. Der Abschnitt einer Version erscheint in der App als „Was ist neu“.

## [1.0.0] - 2026-11-07

Erste Version 🎉

- Lebensmittel erfassen, nach Supermarkt-Kategorien oder Datum sortiert
- Barcode scannen: Name und Kategorie kommen automatisch von Open Food Facts
- Datum von der Packung per Kamera ablesen
- „Mindestens haltbar bis“ mit einstellbarem Puffer (Standard 3 Tage), „Zu verbrauchen bis“ ohne Puffer
- Tägliche Erinnerung mit Vorwarnung
- Dark Mode
- Automatische Updates über GitHub
